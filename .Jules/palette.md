## 2025-03-01 - Floating Action Button Tooltip Accessibility
**Learning:** Tooltips designed for floating action buttons (like WhatsApp links) that rely exclusively on `group-hover` for visibility remain entirely invisible to keyboard users who tab through interactive elements, even though the link itself receives focus. Since these buttons usually rely on icons for their primary visual label, keyboard-only users miss the contextual description provided by the tooltip.
**Action:** Always ensure that `group-hover` visibility classes are mirrored with `group-focus-visible` classes (e.g., `group-focus-visible:opacity-100 group-focus-visible:translate-x-0`). This ensures equivalent UX and accessible context for both mouse and keyboard navigation, alongside standard focus ring styling.
