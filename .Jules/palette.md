## 2025-03-02 - Floating Action Button Focus Parity
**Learning:** For floating action buttons with hover-based tooltips (using Tailwind's `group` and `group-hover` classes), keyboard users often miss the visual context because `focus` does not trigger the tooltip by default. Also, if the button shape is circular, default focus rings appear square unless explicitly shaped.
**Action:** Always mirror `group-hover` tooltip classes with `group-focus-visible` classes (e.g., `group-focus-visible:opacity-100 group-focus-visible:translate-x-0`). Additionally, apply `rounded-full` to the parent `<a>` or `<button>` along with `focus-visible:ring-2` to ensure the focus ring matches the button's shape. Use `aria-hidden="true"` on the visual tooltip if an `aria-label` already covers the interaction intent to prevent screen reader redundancy.
