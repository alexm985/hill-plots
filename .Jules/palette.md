## 2024-08-11 - Mirroring Hover Tooltips for Keyboard Accessibility
**Learning:** When adding Tailwind `group-hover` tooltips or scale effects to interactive elements (like custom icon buttons), users relying on keyboard navigation miss critical context if the tooltip doesn't appear on focus. Furthermore, nested icons and decorative elements inside links need `aria-hidden="true"` to prevent screen readers from reading meaningless visual noise alongside the primary `aria-label`.
**Action:** Always mirror `group-hover` classes with `group-focus-visible` (e.g., `group-hover:opacity-100 group-focus-visible:opacity-100`) and apply `focus-visible:ring` to the parent interactive element. Always apply `aria-hidden="true"` to inner decorative elements (like `<i>` tags and tooltip divs) when a descriptive `aria-label` is already set on the parent.
