## 2024-05-24 - Improve Area Calculator Validation UX
**Learning:** Native browser `alert()` popups are exceptionally disruptive for form validation and present severe accessibility issues for screen reader users as they interrupt the flow and don't cleanly associate with the erroneous fields. Additionally, unlinked `<label>` and `<input>` elements in custom forms prevent users from clicking the label to focus the input, which is a key interaction pattern, especially on mobile devices.
**Action:** Always replace native `alert()` validation with conditionally rendered inline error messages tied to state. These messages must include `role="alert"` so assistive technologies announce them immediately. Concurrently, always ensure custom form fields are explicitly linked to their labels using unique `id` and `htmlFor` attributes to maximize the clickable focus area.
