## 2025-03-10 - Hover-based Tooltips and Keyboard Focus on Custom Shapes
 **Learning:** In Tailwind CSS, hover-based tooltips implemented using `group-hover` exclude keyboard users if not explicitly mirrored with `group-focus-visible`. Additionally, when applying `focus-visible:ring` to non-rectangular interactive elements (like circular floating action buttons), the parent interactive element (e.g., `<a>` or `<button>`) must have matching border-radius classes (e.g., `rounded-full`) and display properties (e.g., `inline-block`) for the focus ring to shape and position correctly.
 **Action:** Always pair `group-hover` interactive visual cues with `group-focus-visible` classes. For circular or custom-shaped interactive elements, explicitly ensure the focus target wrapper shares the same structural properties (border-radius and block sizing) as the visual element.
