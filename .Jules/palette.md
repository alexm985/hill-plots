## 2025-03-02 - Accessible Tooltips for Icon-Only Buttons
**Learning:** When using `group-hover` for custom tooltips in Tailwind on icon-only interactive elements, the tooltip often becomes completely inaccessible to keyboard and screen reader users. The interactive parent requires an `aria-label` to provide context, making the visual-only tooltip text redundant for screen readers, meaning the tooltip itself must be `aria-hidden`.
**Action:** Always mirror `group-hover` interactions with `group-focus-visible` to ensure keyboard users can trigger the visual tooltip. Add `aria-hidden="true"` to supplementary visual elements (like icons and tooltips) when their meaning is covered by an `aria-label` on the parent interactive element. Ensure the parent element has proper focus styling (`focus-visible:ring-2`) and `border-radius` classes so the focus ring shapes correctly.
