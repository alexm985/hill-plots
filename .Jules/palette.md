## 2025-01-29 - Missing `aria-label` and `aria-hidden` attributes on FontAwesome icons
**Learning:** It's a common pattern in this project to use FontAwesome icons inside anchor tags for social links and chat buttons without proper `aria-label` attributes on the anchor tags or `aria-hidden="true"` on the icon tags, impacting screen reader accessibility. I observed this in `App.tsx`, `components/Header.tsx`, `components/ContactForm.tsx`, and `components/WhatsAppButton.tsx`.
**Action:** When adding or updating icon-only interactive elements, ensure to add a descriptive `aria-label` to the interactive container (like an `<a>` or `<button>`) and `aria-hidden="true"` to the inner `<i>` icon element. Also remember to add `focus-visible` styles so that keyboard navigation users can clearly see the focus state.
