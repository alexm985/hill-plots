## 2023-11-28 - Mirroring Hover Animations with Focus for Floating Elements
**Learning:** Animated floating UI elements (like a WhatsApp button with hover tooltips and scale effects) are often completely inaccessible to keyboard users if animations only rely on hover. Without a focus-visible outline on the parent `<a>` or `<button>`, users can't see when it has focus, and without mirroring `group-hover` with `group-focus-visible`, they miss supplementary context.
**Action:** Always add `rounded-full` to circular interactive parents to shape `focus-visible:ring` correctly, and explicitly pair `group-hover:*` utility classes with `group-focus-visible:*` classes (e.g., `group-focus-visible:opacity-100 group-focus-visible:translate-x-0`) to ensure parity between mouse and keyboard experiences.
