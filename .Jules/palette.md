## 2024-03-04 - Accessible Tooltips for Floating Action Buttons
**Learning:** Floating action buttons with visual tooltips triggered by `group-hover` fail for keyboard navigation unless `group-focus-visible` is implemented. Additionally, screen readers require explicit `aria-label` on the parent interactive element and `aria-hidden="true"` on purely visual supplementary elements like icons and decorative tooltips.
**Action:** Always mirror `group-hover` state classes with `group-focus-visible` to ensure keyboard accessibility. Provide text equivalent via `aria-label` on the link/button and hide the visual tooltip and icon from screen readers to prevent redundant reading. Make sure to use `inline-block rounded-full` on the parent interactive element so focus rings apply correctly.
