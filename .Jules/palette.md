## 2026-09-18 - Adding accessibility to Font Awesome icon links\n**Learning:** In this project, links that only contain Font Awesome icons need explicit `aria-label` attributes on the parent `<a>`, `aria-hidden="true"` on the `<i>` tag, and appropriate `focus-visible` styling (including `group-focus-visible` for any nested tooltips) to be properly keyboard and screen reader accessible.\n**Action:** Always add these attributes and styles when creating or modifying icon-only interactive elements using Font Awesome.
