## 2025-03-08 - Area Calculator Accessibility & Inline Feedback
**Learning:** In the `AreaCalculator` component, input fields lacked programmatic association with their labels, reducing accessibility for screen readers and mobile tap-to-focus behavior. Additionally, the component was relying on native browser `alert()` dialogs for validation, which blocks the UI thread, interrupts the user experience, and provides poor context for accessibility tools.
**Action:** Always ensure custom input fields explicitly link `id` and `htmlFor` attributes to their respective labels. Consistently prefer conditionally rendered inline contextual feedback (using `role="alert"` for a11y announcements) over native browser alerts to create non-blocking and more informative user interactions.
