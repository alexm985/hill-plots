## 2023-10-27 - WhatsApp Button Keyboard Accessibility and Screen Reader Improvements
**Learning:** When adding hover-based animations or tooltips using Tailwind (like `group-hover`), it is critical to consistently mirror them with `group-focus-visible` so keyboard users have the same experience as mouse users. Additionally, when using icon-only buttons with supplementary tooltips, the parent interactive element (`<a>` or `<button>`) needs a descriptive `aria-label`, and the supplementary visual elements (`<i>` and the tooltip `<div>`) should have `aria-hidden="true"` to prevent redundant or confusing screen reader output. Also, parent interactive elements should have appropriate border-radius classes (e.g., `rounded-full`) so `focus-visible:ring` shapes correctly around circular children.
**Action:** Always ensure custom hover tooltips are accompanied by focus-visible variants, apply `aria-hidden="true"` to decorative icons and visual tooltips, and add `aria-label` to the parent interactive container. Check border-radius classes on parent containers to ensure focus rings match the shape of the elements they enclose.
