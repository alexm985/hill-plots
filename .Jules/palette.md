## 2024-08-14 - Accessible Floating Action Buttons with Tooltips
 **Learning:** When adding tooltips to floating action buttons (like a WhatsApp chat button) using `group-hover`, keyboard users are often excluded from seeing the tooltip because focus doesn't trigger the hover state. Furthermore, if the interactive container (`<a>` or `<button>`) lacks an `aria-label`, screen readers will just read "WhatsApp" from the icon (or nothing, if it's just an SVG) instead of "Chat with us".
 **Action:** Always mirror `group-hover` classes with `group-focus-visible` classes on tooltips. Add `aria-label` to the parent interactive element and `aria-hidden="true"` to supplementary visual elements like icons and tooltips so screen readers get a clean, single announcement. Also ensure the parent has appropriate border-radius (e.g. `rounded-full`) so `focus-visible:ring` shapes correctly around circular children.
