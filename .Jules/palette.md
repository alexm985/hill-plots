## 2026-03-25 - Replaced Native Alert with Inline Validation in Calculator
**Learning:** Native `alert()` dialogues are jarring, interrupt the user flow, and provide a poor experience on both mobile and desktop. They also lack proper context for screen readers. Using inline, conditionally rendered error messages with `role="alert"` provides immediate, non-intrusive feedback that screen readers announce properly. Additionally, explicitly linking custom form inputs with their labels via `id` and `htmlFor` is crucial for a11y context and allows users (especially on mobile) to click the label to focus the input.
**Action:** Always favor inline validation messages with ARIA roles over native alerts. Ensure all custom form elements have properly linked labels using `htmlFor` and `id`.
