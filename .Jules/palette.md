## 2025-03-01 - Interactive Hover Elements & Focus Visibility
**Learning:** When using Tailwind CSS `group-hover` utilities to display tooltips or trigger animations (like scaling a button or showing text) on icon-only interactive elements, these critical visual feedbacks are entirely lost to keyboard-only users navigating via `<Tab>`. Additionally, icon components (`<i>`) and visual tooltip text (`<div>`) within interactive buttons often lack semantic hiding, resulting in redundant or confusing screen reader announcements.
**Action:** Always mirror `group-hover` utilities with their `group-focus-visible` equivalents (e.g., `group-hover:opacity-100 group-focus-visible:opacity-100`). Ensure the parent interactive element (`<a>`, `<button>`) receives an explicit `aria-label`, possesses a clear `focus-visible:ring`, and that all supplementary visual child elements (`<i>`, text-based tooltips) are masked from assistive technologies using `aria-hidden="true"`.
