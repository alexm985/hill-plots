## 2024-09-23 - Improve Form Accessibility and Error Handling\n**Learning:** Relying on native `alert()` for form validation interrupts the user flow and is poor for accessibility. Form inputs also often lack proper `id` and `htmlFor` linkage which affects screen reader usability.\n**Action:** Use conditionally rendered inline error messages with `role="alert"` and always link labels to their inputs using `htmlFor` and `id`.
