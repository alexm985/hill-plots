## 2024-03-24 - Interactive Icon Accessibility and Focus States
**Learning:** This project relies heavily on FontAwesome icons for interactive elements (like the mobile menu toggle, social links, and WhatsApp floating button) without visible text. Missing `aria-label`s on parent interactive elements and missing `aria-hidden="true"` on the icon tags make these inaccessible to screen readers. Furthermore, a lack of `focus-visible` styles makes keyboard navigation difficult to track.
**Action:** Always ensure that icon-only interactive elements (like anchors or buttons) have an explicit, descriptive `aria-label`, the child `<i>` (or `<svg>`) tags have `aria-hidden="true"`, and the element includes `focus-visible` styling (e.g., `focus:outline-none focus-visible:ring-2`) to provide a clear focus ring for keyboard users.
