## 2024-03-22 - Replaced native alerts with inline accessible validation and linked labels to inputs
**Learning:** Relying on native `alert()` for form validation is disruptive and inaccessible. Using inline error messages with `role="alert"` provides immediate, smooth feedback that is friendly to screen readers. Additionally, failing to explicitly link custom form `<label>`s with `htmlFor` to their `<input>`s by `id` creates poor accessibility and hinders click-to-focus behavior on mobile devices.
**Action:** Always avoid `alert()` for form validation by conditionally rendering an inline error message with `role="alert"`. Furthermore, when constructing custom forms, explicitly assign and link `htmlFor` on the `<label>` to the corresponding `id` on the `<input>` to ensure correct focus behavior and screen-reader association.
