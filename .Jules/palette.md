## 2024-03-08 - Fixed WhatsApp button focus states and tooltip accessibility
**Learning:** When using Tailwind CSS `group` classes to trigger child animations/tooltips on mouse hover (`group-hover`), these are not automatically triggered via keyboard navigation (`tab`), which breaks accessibility. Also, interactive anchors missing `rounded` classes will render an ugly rectangular focus ring even if their children are circular.
**Action:** Always pair `group-hover` with `group-focus-visible` on child elements so keyboard users get the same interactive experience as mouse users. Also, ensure the parent interactive element (the `<a>` or `<button>`) has `rounded-full` or similar if the internal content is circular, to ensure `focus-visible:ring-2` draws a properly shaped focus indicator.
