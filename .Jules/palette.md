## 2024-05-15 - Missing ARIA Labels and Interaction Parity on Icon-only Elements
**Learning:** The application heavily utilizes Font Awesome icon-only links (like the WhatsApp float button and footer social media links) that lack accessible text via `aria-label`, screen-reader hiding for the icons themselves, and keyboard focus indications (`focus-visible`). Additionally, complex UI interactions like tooltips appearing on hover (`group-hover`) are not mapped to equivalent keyboard interactions (`group-focus-visible`), breaking parity for keyboard users.
**Action:** Always wrap icon-only interactive elements (`<a>`, `<button>`) with an `aria-label`, add `aria-hidden="true"` to visual-only elements (like the `<i>` tag), ensure visible focus outlines using Tailwind (e.g., `focus:outline-none focus-visible:ring-2`), and systematically mirror `group-hover` utilities with `group-focus-visible` to ensure tooltips and interactive animations are accessible to keyboard navigators.
