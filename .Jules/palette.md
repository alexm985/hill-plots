## 2026-07-13 - Screen Reader Redundancy in Icon Buttons with Tooltips
**Learning:** Icon buttons that display visual tooltips on hover (like the WhatsApp floating action button) can cause confusing, duplicate announcements for screen reader users if both the button and its visual child elements are readable by assistive technologies. Simply wrapping an interactive element requires explicit `aria-label` for the action while hiding visual children using `aria-hidden="true"`.
**Action:** When creating icon-only buttons with visual text tooltips, always add an `aria-label` to the main interactive element (button/anchor) describing the action, and apply `aria-hidden="true"` to both the icon (e.g., `<i>` tag) and the visual tooltip container to ensure a clean, single announcement.
