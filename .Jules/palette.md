## 2024-07-09 - Accessible Icon-Only Links in React
**Learning:** Icon-only interactive elements (like social media links or floating action buttons using `<i>` tags for FontAwesome) are completely invisible to screen readers without proper labels. Additionally, they often lack clear focus indicators for keyboard navigation unless explicitly styled.
**Action:** When creating icon-only buttons or links, always add an descriptive `aria-label` to the interactive wrapper element (e.g., `<a>` or `<button>`), add `aria-hidden="true"` to the decorative icon tag (e.g., `<i>` or `<svg>`), and apply focus-visible styling (e.g., `focus-visible:outline-none focus-visible:ring-2 ...`) to ensure keyboard accessibility. Ensure appropriate border-radius (e.g., `rounded-full` or `rounded-sm`) is set so the focus ring shapes correctly around the element.
