## 2024-05-19 - Accessible Floating Action Buttons
**Learning:** Icon-only floating action buttons (like WhatsApp widgets) are frequently missed during keyboard navigation and screen reader audits. Tooltips added via pseudo-classes or sibling elements often don't appear on focus, leaving keyboard users without context.
**Action:** When adding hover-based tooltips or scaling animations using Tailwind (`group-hover`), consistently mirror them with `group-focus-visible`. Ensure parent interactive elements (`<a>` or `<button>`) have appropriate border-radius classes (e.g., `rounded-full`) so `focus-visible:ring` shapes correctly, and add `aria-hidden="true"` to supplementary visual elements (like icons and tooltips) to prevent screen reader redundancy when the parent has an `aria-label`.
