## 2026-04-02 - Form Labels & Icon Button Accessibility\n**Learning:** The project extensively uses custom unlinked form components (missing `id` and `htmlFor`) which degrades mobile experience and screen reader support. It also uses Font Awesome icons within buttons/anchors without visible text but missing `aria-label` attributes.\n**Action:** Always ensure custom form components have their `id` and `htmlFor` attributes actively linked for proper accessibility and mobile click-to-focus behavior. For icon-only buttons, always ensure `aria-label` attributes are added to the parent interactive elements and `aria-hidden="true"` is added to the `<i>` tags.
