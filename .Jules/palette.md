## 2025-05-06 - Floating Action Button (FAB) Accessibility
**Learning:** Floating Action Buttons (FABs), like the WhatsApp chat button, often consist solely of an icon without visible text. This makes them inaccessible to screen readers without an explicit `aria-label`. Furthermore, because they are typically `position: fixed`, they can easily be overlooked during keyboard navigation if they lack clear `focus-visible` styling with sufficient contrast against changing backgrounds.
**Action:** Always ensure any icon-only FAB includes a descriptive `aria-label` on the interactive element (e.g., `<a>` or `<button>`), adds `aria-hidden="true"` to the decorative icon itself, and implements strong `focus-visible` ring styling (using `ring-offset` if necessary) to guarantee keyboard accessibility regardless of the content scrolling beneath it.
