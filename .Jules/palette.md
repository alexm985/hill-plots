## 2025-03-05 - Keyboard Focus Animation Mirroring on Floating Buttons
**Learning:** When tooltips or hover animations (like scale) rely on Tailwind's `group-hover` applied to a parent interactive element, keyboard users miss out on this context entirely unless the interaction is explicitly mirrored for focus states. Floating icon-only elements also require explicit border-radius (e.g. `rounded-full`) on the interactive parent `<a>` or `<button>` itself, otherwise the standard keyboard focus ring will appear square around a circular element, creating a jagged visual experience.
**Action:** Always pair `group-hover` utility classes with their `group-focus-visible` equivalents for tooltips and transform animations on interactive groups. Verify that the parent interactive element has border-radius classes matching its visual child element so `focus-visible:ring` wraps it cleanly.
