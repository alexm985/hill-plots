## 2024-05-18 - Focus Ring Mirroring on Custom Interactive Components
**Learning:** In projects heavily utilizing Font Awesome icons and custom CSS animations (like pinging tooltips) within interactive anchors or buttons, native keyboard focus lacks parity with mouse hover states. Specifically, 'group-hover' utilities animating tooltips or scaling elements aren't triggered during keyboard tab navigation, leaving visually impaired users unaware of interactive capabilities and sighted keyboard users lacking visual feedback.
**Action:** When auditing or implementing interactive elements containing custom hover tooltips or scale effects, ensure the parent element utilizes 'focus:outline-none focus-visible:ring-x' and mirrors all 'group-hover' visual cues using 'group-focus-visible'. Combine this with 'aria-hidden="true"' on purely decorative child elements (like tooltips mapping the same text as the parent's 'aria-label').
