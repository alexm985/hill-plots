## 2025-03-08 - Accessible WhatsApp floating button
**Learning:** In a project extensively using Font Awesome icons within interactive elements without visible text, ensuring floating action buttons (like a WhatsApp button) have an `aria-label`, correct focus visibility styling `focus-visible`, and mirrored hover states for keyboard navigation is critical for inclusivity and seamless accessibility.
**Action:** Always ensure an `aria-label` is appended to icon-only anchors or buttons. Make sure supplementary visual cues (icons and tooltips) have `aria-hidden="true"`, and the keyboard focus (`focus-visible`) handles shapes matching the target component, such as adding `rounded-full` to a circular button wrapper, and mirroring animation scaling/visibility from hover states.
