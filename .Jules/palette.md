## 2025-03-08 - Accessible Tooltip Animations
**Learning:** In this project, interactive elements often use Tailwind `group-hover` modifiers to animate nested tooltips or UI components (like in the floating WhatsApp button). Screen reader users are usually provided with an `aria-label` to announce the button's purpose, but keyboard navigation users who rely on visual feedback can miss out on these tooltips if the `group-hover` styles are not complemented with `group-focus-visible` styles.
**Action:** When adding or encountering interactive elements with hover-based tooltips or animations (using `group-hover`), ensure that matching `group-focus-visible` modifiers are also applied to provide the exact same visual cues for keyboard users, and confirm the parent element has proper `focus:outline-none focus-visible:ring-*` styles.
